# Carson Erg Engine

The erg-native programming style for building a big "engine" — most useful
when the athlete wants structured erg blocks with automatic split-level
verification, or as the erg backbone of a Hyrox base phase.

**Coaching notes.** Highest data quality of any style when C2 sync cooperates
(opportunistic — spec §5): per-split watts make interval verification exact.
When sync fails, fall back to photo + Health evidence like any tier-2 session.
