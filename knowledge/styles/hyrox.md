# Hyrox / Hybrid Competition

The one goal track where mixed-modal complexity is justified — compromised
running, sled work, and transitions are the actual competitive skills.

**Coaching notes.** Tier 3 by nature: score session-level proxies (duration,
HR profile plausibility, kcal) plus whatever objective islands exist (run
pace, erg splits), and label every score with its confidence. Phase 4 scope in
the spec — the KB entry exists now so `/coach setup` can set honest
expectations about base-first sequencing.
